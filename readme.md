> This fork is being modernised — see [docs/modernisation/PLAN.md](docs/modernisation/PLAN.md).

## Development

Requires Node.js 24+ and pnpm 10.

```sh
pnpm install
pnpm dev
```

See [docs/build.md](docs/build.md) for all commands.
