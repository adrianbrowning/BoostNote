Each command in this table is also an item in the menu bar. The menu shows the same shortcut next to
the item. Undo, Redo, Cut, Copy, Paste and Select All in the **Edit** menu use the standard keys of
your system, so this table does not list them.

<ShortcutTable />

The two hotkeys that work from any app (show or hide Boostnote, and Quick capture) are set in
Preferences. See [Customise](/BoostNote/guides/customise/) and
[Quick capture](/BoostNote/guides/quick-capture/). The keys you use while you type in a note are in
[Write notes](/BoostNote/guides/write-notes/).
